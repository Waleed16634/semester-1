# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | Shows the current location of the terminal |
|     ls                      | Shows the files and directories in the directory the user is currently in
|     cd directory_name       | Moves from the current directory to a different specified directory
|     cd ..                   | Moves the current directory up one level in the parent folder
|     cd -                    | Goes back to the previous directory
|     mkdir directory_name    | Creates a new directory (name is for what the user names the new directory)
|     touch filename          | Creates an empty file with a name the user gives it if it doesn’t exist
|     git status              | Shows which files have changed and which ones are new
|     git add -A              | Saves all the users changes into the next commit
|     git commit -m ""        | Saves all the users staged changed with a note showing what the user did
|     git push                | Uploads the users commits to the remote repository
|     git pull                | Downloads the changes from the remote repository and puts them into the current branch
